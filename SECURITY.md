# Security

This library performs local date calculations and makes no network requests.
Incorrect delivery calculations can still affect business decisions.

Do not post secrets, personal records or exploitable sensitive details in public
issues. Use the repository Security tab's private vulnerability reporting flow:
https://github.com/tuanthaidnc/commerce-calendar/security/advisories/new

Only 0.1.x is currently maintained. No response-time SLA is offered.
