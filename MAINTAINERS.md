# Maintenance

Lead maintainer: [Thái Văn Tuấn (@tuanthaidnc)](https://github.com/tuanthaidnc).

## Review and release

Calendar behavior changes need an independently checked regression example,
passing CI, API documentation updates and compatibility notes. Maintainers
review proposed changes before merging. Release tags identify immutable source
snapshots; main may include later documentation and checks.

## Reports

Use public issues for reproducible bugs and feature proposals, with synthetic
data. Use private vulnerability reporting for sensitive security reports.
There is no guaranteed response-time SLA or paid support arrangement.

## AI assistance

Codex assists implementation, documentation and tests. Maintainer review and
reproducible checks remain necessary. AI assistance is not evidence of community
adoption, independent review or security certification.
